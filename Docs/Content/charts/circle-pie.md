Each slice is its share of the total. Values can be any scale — Charty works out the percentages.

```charty
{
  "title": "Source lines by language",
  "caption": "A typical mixed Apple-platform codebase",
  "type": "pie",
  "data": [
    {
      "label": "Swift",
      "value": 48210
    },
    {
      "label": "Objective-C",
      "value": 12640
    },
    {
      "label": "C",
      "value": 4380
    },
    {
      "label": "Metal",
      "value": 1120
    }
  ]
}
```
