Values are fractions between 0 and 1, taken at face value. They need not add up to a whole circle, which makes this useful for showing progress.

```charty
{
  "title": "Swift 6 migration",
  "caption": "Targets moved to strict concurrency",
  "type": "sectional",
  "data": [
    {
      "label": "Complete",
      "value": 0.55
    },
    {
      "label": "In review",
      "value": 0.18
    },
    {
      "label": "Blocked",
      "value": 0.07
    }
  ]
}
```
